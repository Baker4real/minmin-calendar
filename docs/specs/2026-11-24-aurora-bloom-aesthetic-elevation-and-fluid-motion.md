# Aurora Bloom 深度审美跃迁、物理景深重塑与流体状态交互升级

**Issue:** [#263](https://github.com/Baker4real/minmin-calendar/issues/263)

## Problem Statement

敏敏子日历是一款供伴侣双方私密共享经期记录、周期预测与欢乐时光的微信小程序。在前序暗夜极光（Aurora Bloom）视觉收敛完成后，项目的领域边界、对比度下限、读屏语义与状态同步底座已经稳固；但在 2026-11-24 基于全仓源码、静态反模式检测器与二十二张替身房间真实渲染画面的深度审美与交互审计中，界面距离令人第一眼心动的高定级双人私密手账仍存在五道明显断层：局部组件出现肉眼可见的渲染反转与排版事故、大面积均质深蓝实底封死了极光呼吸感与控件物理景深、首页与设置页堆叠过多同质化一像素线框、系统裸字符充当图标且欢乐时光缺乏情感温度、以及触摸按压滞留与多处状态硬切跳变拉低了指尖操控质感。本规格将本次全面审美审计产出的全部修复项与六大系统级美学跃迁方向悉数纳入，一次性完成从合格工程界面到细腻、灵动、温润精品的全面升级。

### 目标与已确认选择

- **全量纳入审计建议**：本次全面审美审计第一部分的全部六项即刻工艺修复，以及第二部分的全部六大系统级美学与流体交互升级方向全部纳入本规格实施范围；仅排除违背既有架构决策与平台边界的做法（见 Out of Scope）。
- **首页「回到今天」零跳动内嵌定案**：非当前自然月浏览时，不再在吸顶区内插入独立整行「回到今天」通栏（避免翻月瞬间把整张日历向下顶踹 `88rpx`），改为在月份导航行右侧内嵌一枚固定触控热区的玫瑰细框「今」字胶囊按钮（读屏名称保持「回到今天」），月份胶囊继续严格锁定在屏幕水平中轴线上不偏移，选月面板内仍保留完整的「回到今天」按钮。
- **欢乐时光近月默认展开定案**：取代此前欢乐时光月份卡片默认全部收起的临时安排，改为在页面尚未产生本页手动折叠选择时默认展开最近一个有记录的月份卡片，其余历史月份保持收起并展示条数与首条摘要；手动展开收起的状态保留与保存后展开目标月份的规则保持不变。
- **单机型替身房间验收**：遵循维护者既有决定，不做多机型兼容矩阵测试；运行态统一在微信开发者工具模拟器当前机型上通过替身房间与构造数据验收。
- **全部取舍定案与权威文档同步**：所有视觉尺寸、材质参数、交互时序与旧规替代关系均在本规格内敲定完毕；需依赖运行态或合成对比度实测拍板的边界均写为机械可判定的规则，并同步更新项目视觉规范文档、动效与交互文档、领域上下文文档及对应静态护栏测试。

### 已知事实与约束（2026-11-24 回源核对）

- **自有日期滚轮严重渲染反转**：小程序模板编译器不会转换组件字符串属性内的响应式像素单位，导致滚轮选中指示框高度声明失效并回退至默认 `34px`，与 `88rpx` 行高错位下偏至第四行；同时内置遮罩样式使用了背景简写属性，重置了原生遮罩的不平铺与半高尺寸设置，导致遮罩纵向重复平铺两次以上——正中央选中行反被遮成暗灰，而上下未选中的第二行与第五行却惨白刺眼，且滚轮两侧贴死槽边。
- **分享卡排版事故、源图标噪点与底栏配重失衡**：静态邀请分享卡副标题「把这一份温柔，留给我们」因逐字按字形墨迹包围盒顶对齐绘制，导致「一」字漂移至字框顶端形如上划线、全角逗号漂移至右上角形如撇号，双层琉璃心左叶高光弧线穿透内外心暗缝，四角暗部存在索引色块状色阶；应用源图标右上角残留孤立白噪点且四角预裁边生硬；底栏设置齿轮实心厚环加粗齿的墨迹面积约为日历与记录图标的一点八倍，视觉重心右倾。当前整包图片与音频资源合计约 `80 KB`，距 `200 KB` 质量上限尚有约 `120 KB` 余量。
- **固定顶栏透字鬼影与启动页空顶栏割裂**：共享固定顶栏未开启背景模糊且存在约百分之八透光率，长表单向上滚动经过顶栏下方时白色文字透出清晰重影；编辑页左上角圆角方框返回钮与首页左上角轻玻璃胶囊工具钮造型语言割裂；启动首屏无标题也无左侧按钮，却仍挂载带底分隔线与光斑的空顶栏，将完整极光夜空生硬截断。
- **底部弹层滚动条外露、同心圆失配与文案断行瑕疵**：共享底部弹层将纵向滚动直接挂在带 `36rpx` 大圆角的外层面板上，内容较长时裸露粗亮系统灰白滚动条切破圆角边缘，且顶部把手、标题与关闭按钮随长内容滚走；弹层外圆角 `36rpx` 配内层卡片 `20rpx` 圆角，但水平内边距仅 `22rpx`，内容紧逼弧边；关闭圆钮在 `88rpx` 实底圆框内放 `46rpx` 叉号显得头重脚轻；本月小结弹层主标题打印年月后再于副标题重复打印同一年月，明细行以冒号与逗号拼成数据库日志式长串，预测说明五句灰字裸排缺少核心视觉锚点；全站十八处流式中文使用任意字符断行策略，导致日期在「日」字前被拆行或句末标点孤字落行，数字与量词间距写法不一。
- **材质景深扁平与主按钮常驻粉雾**：全站高级卡片四边画死等亮白边，且平白内顶线与极光棱镜顶线叠在同一像素行；卡片内输入框与日期选择器使用与卡片同亮度的浅白叠层，缺乏「凸起毛玻璃卡与内凹书写槽」的物理层次；实色主按钮与复制键的柔光伪元素在静止态常驻全亮玫瑰阴影，边缘泛起浑浊粉雾并泄漏到绑定页半透明票根复制钮上，票根复制钮在窄内边距加 `88rpx` 高度下挤成胖圆块，设置页房间卡配对徽标右推顶撞复制钮且等待态同卡出现两枚实色亮粉按钮互相抢戏。
- **首页多框线套娃、日历格邻近性失真与骨架视错觉**：首页自上而下堆叠七至八层带一像素描边的横条与套娃框（顶栏底线、吸顶底线、月份外卡框、月份内胶囊框、等待邀请条、周头框、日历框、双快捷钮、小结框、底栏顶线）；日历格节日行在无节假日的绝大多数日常日期仍死占 `38rpx` 或 `34rpx` 空白，把当日欢乐时光心形与预测标记推到格子最底端，使其离下一周日期比离本日农历还近，且经期中的今天胶囊下沿与色带上沿紧贴粘连，日期格按压缺少微底色反馈，预测叠欢乐时光时心形与「预」字垂直中心错位；左下主快捷按钮在玫瑰底上挖出纯黑圆洞且内部暗粉条难以辨认；首页骨架屏三十五个圆角格紧挨产生二十四个十字暗星视错觉，记录页首次加载骨架中间突兀暴露全亮「记经期」实色按钮并在加载后突变为「记结束」。
- **裸文本符号碎片化与双人情感触点冷感**：全站使用系统文本字符充当左右箭头、下拉角标、关闭叉号与加号，衍生出六档字号特例与跨系统基线漂移；各类小胶囊标签采用行高等于高度加描边的写法导致文字视觉下沉；页面样式仍残留两处硬编码玫瑰色十六进制背景值；启动首屏与首页未绑定空态仅放一颗单薄系统文本心形；记录页欢乐时光分段缺少与周期概览对称的情感题头卡，列表行把伴侣写下的珍贵内容压成 `26rpx` 次要灰字单行截断而把日期放成主字，欢乐时光编辑页保留冰冷的「日期 / 内容」后台管理标签；经期编辑页把状态、经量与症状全部画成十三枚同质化 `88rpx` 实色发光胶囊墙；设置页「重新同步房间」混在房间名片底部而「数据」分组仅剩单行「导出数据」独立成卡。
- **触摸粘滞与状态瞬移硬切**：全站可点视图组件未显式声明触摸起止时间，落入微信默认 `50ms` 延迟与 `400ms` 松手滞留，配合对称按压过渡造成连点粘肉感；三处分段控件缺少实体滑块，切换仅靠文字描边变色；首页横滑翻月手指移动期间画面死板不动、入场仅位移微弱的 `10rpx`；经期编辑「结束日期」字段显隐、绑定页子表单展开与记录页年月折叠均为零毫秒硬切，经期备注聚焦时底部保存栏直接瞬时消失；记录页下拉刷新在分段控件下方硬插状态行把整页往下顶踹；弹层下拉手势按全程平均速度计算，停顿细看后再快速下甩无法顺畅关闭，且选中态芯片光晕切换存在硬闪。

### 关键失效方式

1. **视觉焦点倒置与排版失真**：暗光下打开日期滚轮，未选中行惨白刺眼而中央选中行昏暗下偏；转发给伴侣的邀请卡片副标题字形漂移变形，第一眼折损产品精致度与信任感。
2. **滚动鬼影与边缘破相**：编辑页滚动时白色日期文字在顶栏透出重影；打开使用说明或长弹层时粗灰滚动条切破圆角毛玻璃，把手与关闭钮滚出可视区。
3. **框线密集疲劳与跨行误读**：首页层层叠叠的平行框线让日历显得局促机械，无节日日期的心形标记悬在下一周日期头顶，扫读时极易张冠李戴；翻看往月或下拉刷新时整屏上下跳动。
4. **情感触点冰冷与多选轰炸**：记录共同点滴的欢乐时光像在填后台工单、回看时满屏折叠灰条且正文被截断降级；经期多选几个症状就亮起大片刺眼实色粉块，淹没底部真正的保存主按钮。
5. **操控粘滞与空间断裂**：点按控件松手后按压态滞留近半秒，切换分段、折叠月份、呼出软键盘或横滑翻月时缺少连续物理反馈，手感生硬断裂。

## Solution

全部改动落地后，从伴侣双方的日常视角体验：

- **日期滚轮精准聚焦、分享与图标锐利均衡**：打开任意日期面板，五行的行高与中央暖玫瑰选中框像素级严丝合缝，外置上下深海军渐变遮罩平顺消隐边缘行，唯独正中央选中日期清亮醒目；微信邀请卡文字基线端正优雅、双层琉璃心高光收束自然、暗部极光丝滑无色带；三枚底栏图标升级为三倍超采样高清圆润线型，设置齿轮与日历、记录图标轻重如一。
- **顶栏柔雾防透字、启动首屏一望无际**：全站常规固定顶栏自带细腻背景毛玻璃模糊，长表单滚入顶栏下方时柔和化开绝无文字重影，返回圆钮与图例胶囊同享轻玻璃语言；启动首屏顶栏完全透明沉浸无分隔线，交叠双琉璃心徽章在完整极光夜空下呼吸绽放，建房成功时副心与星环向外轻漾涟漪。
- **底部弹层纯净同心、小结与预测层次井然**：所有底部弹层把手与标题行稳固常驻，内容在隐藏系统滚动条的内层区域顺滑滚动，内外圆角同心舒展、关闭圆钮轻巧精致；本月小结不再重复打印年月，明细以紧凑日期徽标配清爽正文呈现；预测说明顶部核心结论嵌在暖金细边轻玻璃主卡中；全站中文段落与日期数字断行自然，绝不拆碎日期或留下标点孤字。
- **光影景深立体可触、凭证名片纯粹内敛**：全站高级卡片呈自然顶光折射——顶缘亮、侧边柔、底边隐，微透背后极光漫射；卡片内的输入框与日期选择器下沉为带微内影的深海丝绒凹槽，聚焦时泛起柔和玫瑰光环；实色玫瑰主按钮顶缘带一抹清脆微高光、静止态告别浑浊粉雾；绑定页与设置页共用精致内凹房间凭证票根与修长淡玫瑰复制胶囊，设置页徽标左聚不撞按钮，「重新同步房间」归入「数据」双行卡，顶部名片清爽纯粹。
- **首页去框通透、标记紧随当日、翻月零跳动**：首页拆掉月份外层套娃框，周头与日期网格融为一整张无割裂手账日历，等待邀请条上下留出呼吸余量，左下「记经期 / 记结束」主按钮左侧换上温润同系暗压痕胶囊图标；无节日日期的欢乐时光心形与「预」字紧贴当日农历或经期色带下方，经期中的今天胶囊与色带之间留出清晰暗缝；翻至非当月时，月份栏右侧悄然浮现「今」字玫瑰胶囊，日历棋盘纹丝不跳；首页与记录页骨架屏均匀柔和，首次加载不再闪现错误主按钮。
- **矢量图标如钟表精密、欢乐时光温暖如信笺**：全站箭头、下拉角标、关闭叉号与加号统一换用圆端几何内联矢量图标，小胶囊标签光学绝对居中；欢乐时光分段新增温润题头概览卡、默认展开最近有记录的月份，列表行将伴侣写下的点滴正文升格为双行暖白主字，编辑页化作「心形加日期星期」可点信笺抬头配宽幅丝绒书写槽；经期编辑页以三等分内凹状态轨、三档程度经量块与柔和描边症状胶囊建立清晰三层视觉秩序。
- **指尖触感清脆跟手、状态流转丝滑连贯**：所有可点控件按下瞬时响应、松手轻快回弹；分段切换有玫瑰玻璃滑块顺滑游走并伴随面板微转场；首页日历支持手指横向阻尼跟手微移、边界橡皮筋提示与更舒展的翻月滑入；条件字段与月份卡片平滑伸缩，软键盘弹起时底部保存栏优雅下沉退场；记录页下拉刷新统一走顶栏同步胶囊，弹层下拉支持停顿后再快甩关闭与向上回推取消。

## User Stories

### 自有日期滚轮、品牌图像与顶栏底栏工艺

1. 作为在夜间记录日期的用户，我希望自有日期滚轮中央玫瑰选中框与选中文字像素级居中对齐、上下未选中行平顺渐隐进深海军底，以便一眼锁定当前选中的年月日而不再被错位亮白行晃眼。
2. 作为向伴侣转发房间邀请卡的用户，我希望分享卡片上的副标题汉字与标点基线端正、双层琉璃心高光干净且暗部极光细腻无色块，以便伴侣收到卡片的第一眼就感受到温柔考究的品质。
3. 作为在手机底栏切换「首页 / 记录 / 设置」的用户，我希望三枚底栏图标在高分屏上边缘锐利且「设置」齿轮与「日历」「记录」线条粗细和视觉分量一致，以便底栏整体和谐平衡。
4. 作为上下滚动经期或欢乐时光长表单的用户，我希望固定顶栏通过细腻毛玻璃模糊柔化滚入下方的表单文字，以便顶栏标题与返回按钮始终清晰纯净、不出现叠字鬼影。
5. 作为打开小程序进入启动首屏的用户，我希望首屏顶部没有突兀的空顶栏底线或多余光斑切断极光夜空，以便沉浸在一望无际的完整深海极光画布中。
6. 作为在两个编辑页点按左上角返回的用户，我希望返回按钮与首页左上角图例按钮共享统一的轻玻璃圆润质感与精致几何左箭头，以便跨页面抬头控件语言一脉相承。

### 底部弹层家族、信息弹层与中文排印细节

## Implementation Decisions

### 1. 自有日期滚轮像素级对齐与外置深海遮罩

- **行高与指示框运行时像素同步**：自有日期滚轮状态模块按当前窗口逻辑宽度换算整数单行像素高度（按 `750rpx` 设计宽折算 `88rpx` 并四舍五入取整，缺省窗口宽度时回退 `44px`），面板总高严格取单行像素高度的五倍，把单行像素值与总像素高度下发到日期面板数据。滚轮容器、滚轮视图、每行选项及滚轮组件的选中指示框样式统一绑定该整数像素高度，指示框顶偏移固定为两倍单行像素高度，保留 `10%` 暖玫瑰淡底与上下 `1px` `32%` 暖玫瑰细边，从根源消除组件字符串属性不编译响应式单位造成的 `34px` 错位下偏。
- **关闭内置平铺遮罩并改用外置双层渐变遮罩**：滚轮组件遮罩样式显式设为无背景图像与零边框，彻底关停微信内置遮罩的重复平铺与列间灰线；改由滚轮外层受控容器的上下伪元素绝对定位绘制各占两倍单行像素高度的不平铺线性渐变遮罩——顶层自顶向底由已登记的玻璃回退色 `rgba(18,22,61,0.92)` 过渡至全透明 `rgba(18,22,61,0)`，底层自底向顶对称过渡，设为不拦截点按且层级高于滚轮字层、低于或齐平指示框边线，同时把此前未入色板的近似深蓝遮罩色值收敛回标准深海军色，并为滚轮槽补充适度水平内边距消除贴边局促。既有滚轮惯性滚动锁与代际屏障机制保持不变。

### 2. 高清分享卡真基线重制、满幅源图标与三倍超采样底栏图标

- **静态邀请分享卡工艺重制**：保持 `1000×800`（五比四比例）尺寸、不含任何经期字样与房间码的隐私边界不变。改用整行统一字形基线排版引擎渲染主标题「美少女的日历」与副标题「把这一份温柔，留给我们」，确保汉字「一」稳居汉字中线、全角逗号准确落在左下基线区；中央图形重绘为一暖玫瑰、一柔薰衣草微错位交叠的曲率连续双层半透明琉璃心，左叶高光弧线严格裁剪在心形外壁厚度以内绝不穿模；深海极光背景叠加约百分之一幅度的细腻蓝噪声微抖动消除暗角阶梯色带，单文件体积控制在 `120 KB` 以内（详见判定规则 D1）。
- **应用源图标同步升级**：仓库内保留且不打入上传包的应用源图标重绘为 `1024×1024` 满幅直角正方形高清母版（交由平台统一裁切圆角），采用与邀请卡同源的暗夜极光交叠双琉璃心主视觉，清除右上角孤立白噪点与旧式平直预裁边。
- **底栏三套图标三倍超采样与光学配重均衡**：将「日历」「记录」「设置」未选中与选中共六枚底栏图标统一升级为 `108×108`（三倍超采样）高清 PNG；保留日历顶环方格与记录三行圆点横线的单义识别特征，将「设置」图标重绘为外径内缩约百分之十、与日历和记录同线宽的中空圆润六瓣齿轮，使三枚底栏图标的不透明像素墨迹面积彼此偏差控制在百分之二十以内；全部不透明度达到 `250` 及以上的实色像素严格锁定为未选中 `#7A7C8C` 与选中 `#E8909E`，同步更新底栏图标护栏测试的尺寸常量与配重均衡断言。

### 3. 共享顶栏毛玻璃防透字、沉浸首屏顶栏与编辑返回钮统一

- **常规固定顶栏背景模糊与柔边**：共享固定顶栏表面在保持深海军高不透明度渐变回退底（顶部 `rgba(10,14,39,0.92)` 至底部 `rgba(18,22,61,0.88)`，满足不低于 `0.85` 实色兜底要求）的基础上，成对声明 `14px` 背景模糊与内核前缀背景模糊，底部分隔发丝线柔化为 `1px solid rgba(255,255,255,0.06)`，并将共享顶栏正式登记进视觉规范与动效护栏的模糊表面白名单，阻断滚动表单文字透出重影。
- **启动首屏沉浸式透明顶栏变体**：共享顶栏模板与样式新增启动首屏专用的「沉浸占位」变体供绑定页调用：完整保留状态栏安全区、胶囊推算高度与水平中轴线几何占位，但不绘制顶栏背景填充、不画底部分隔细线、也不挂载顶栏左右浮动光斑伪元素，使启动首屏极光画布从屏幕最顶端完整铺展。
- **编辑页返回钮与顶栏工具钮家族化**：将经期与欢乐时光两个编辑页左上角返回按钮的内部可视表面从厚重方框调整为与首页左上角「图例」一致的 `64rpx` 高轻玻璃圆润表面（外层继续保持至少 `88rpx` 透明触控热区），内部换用共享圆端几何左折角矢量图标并做光学重心微调。

### 4. 底部弹层内层无滚条滚动、同心圆几何、小结与预测升级及中文断行精修

- **把手常驻与内层无滚条滚动**：共享底部弹层面板与确认面板外框改为纵向弹性列布局并设为溢出隐藏，将纵向滚动职责下沉至弹层内容块容器（弹性占满剩余高度、最小高度归零、纵向自动滚动），并对内容块显式隐藏浏览器内核原生滚动条宽高与颜色，确保长内容滚动时顶部拖拽把手、标题与关闭按钮始终固定在面板顶端，且 `36rpx` 外圆角边缘绝不被灰白滚动条切破。
- **内外圆角同心留白与轻量化关闭钮**：将共享底部弹层水平内边距由 `22rpx` 拓宽至 `28rpx`（与外层 `36rpx` 大圆角及内层卡片 `20rpx` 圆角形成光学同心关系，清零紧贴内边距告警）；右上角关闭按钮保持 `88rpx` 透明触控热区，内部可视表面缩减为 `64rpx` 轻薄半透明圆环并承载 `16px` 几何叉号图标；同步优化图例样本内边距并将当日详情记录行的硬边发光侧条柔化为内嵌圆角语义细柱。
- **本月小结去重结构化与预测说明主卡化**：
  - 日历洞察模块输出的本月小结弹层标题固定为四字「本月小结」（与「日历图例」「预测说明」「选择月份」对齐），仅由弹层副标题展示当前浏览年月，消除主副标题上下连续打印两次同一年月；复制导出的纯文本首行继续保留带具体年月的「YYYY年M月小结」完整标题。小结明细项在保持既有跨月覆盖并集天数、当月相交天数与本条持续天数领域规则不变的前提下，补充结构化字段将每条拆分为「紧凑语义色日期徽标 + 清爽摘要正文」两段式排版（保留完整拼接句供读屏与纯文本复制共用）。
  - 首页信息弹层处于「预测说明」模式时，将首句核心预测结论包裹进带暖金色细描边 `rgba(212,165,116,0.28)` 与左侧 `4rpx` 暖金语义微导轨的轻玻璃主卡中（正文文字仍用强调档中性白以严守对比度，将该主卡描边与导轨登记入首页金色语义白名单），下方推算依据句与非医疗建议声明以舒展列表承接。

## Testing Decisions

### 1. 测试原则与最高测试切口

- **只验证外部可观察行为与公开视觉无障碍契约**：所有测试沿着仓库既有的四条最高切口编写——纯状态投影切口、小程序页面运行时模拟器切口、展开共享导入后的模板与样式静态护栏切口、以及微信开发者工具模拟器当前机型替身房间运行态切口；不绑定模块私有辅助函数名，不新增第三方测试框架。

### 2. 纯投影与页面行为测试

- **自有日期滚轮与编辑页交互测试**：验证日期面板按不同窗口宽度算出精确整数单行像素与五倍总高并注入选项及指示框样式，内置遮罩背景关闭且惯性锁继续生效；验证经期编辑页状态切换保留完整无障碍单选组语义、结束日期折叠态正确切换可见与禁用读屏属性、备注聚焦与失焦平滑切换保存栏隐藏态；验证欢乐时光编辑页信笺抬头点击正常拉起日期滚轮且保留最大今天校验与草稿恢复提示。
- **首页日历投影、手势与弹层测试**：验证非当前月浏览时「今」字内嵌胶囊可见、读屏名为「回到今天」、点击跳回当月并点亮今日胶囊光晕，且首屏几何账本不再计入独立 `88rpx` 通栏高度；验证横滑视图脚本在常规月与边界月输出预期跟手阻尼、未达阈值回弹、达阈值触发翻月；验证本月小结弹层标题为「本月小结」、副标题为浏览年月、复制文本首行仍含完整年月小结，且明细项输出日期徽标与摘要分段字段；验证预测说明模式输出主卡结论与依据列表；验证弹层拖拽 `80ms` 瞬时速度支持停顿后快甩关闭及拉下后上推取消。
- **记录页、绑定页与设置页行为测试**：验证记录页首次加载期间不渲染真实新增主按钮而展示骨架占位、下拉刷新驱动顶栏同步状态胶囊而非列表内状态行；验证欢乐时光分段输出共同点滴概览卡统计（总条数与本年条数，未同步时不编造零值），且无手动折叠记录时默认展开最近一个有记录月份、手动切换与保存展开目标月份继续生效；验证设置页「重新同步房间」在「数据」分组内完整走通确认弹层与共享记录重拉流程，房间码复制与配对徽标状态准确。

## Out of Scope

- **引入第三方小程序 UI 组件库、图标字体文件或外部运行时依赖**：严格遵循既有架构决策，所有矢量图标均以零外部依赖的内联样式遮罩实现，不引入外部包或网络字体。
- **迁移至 Skyline 渲染引擎、改用自定义组件重写页面或替换微信原生底栏**：保留现行渲染管线、共享模板样式展开体系与微信原生底栏（底栏第一项标签文案仍保持与领域上下文一致的「首页」，仅升级三倍超采样图标源文件）。
- **将保存或同步失败的系统级中断弹窗改为应用内面板**：按既有确认与反馈分层决策，确认类交互走应用内底部弹层，失败恢复提示继续保留原生弹窗。
- **修改周期预测数学模型、经期三态业务规则、跨月并集统计算法、云函数代码或数据库索引**：本次升级聚焦前端视觉美学、物理景深、排印图标、情感化表达与流体交互手感，不改动任何云端逻辑与领域数据契约。
- **跨机型物理真机矩阵测试**：按维护者既有决定，运行态仅在微信开发者工具模拟器当前机型上完成验收；真机线性马达体感、真机读屏逐句实听与原生转发面板宿主渲染列为已知边界。
