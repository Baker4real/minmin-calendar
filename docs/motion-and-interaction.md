# Aurora Bloom 动效与交互

本文从 `DESIGN.md` 下沉出来，和它一起是 Aurora Bloom 的唯一现行视觉说明。缓动、时长与延迟，翻月滑入与日历强调，记录成功反馈，弹层的进出、错相与遮挡暂停，同步胶囊与失败恢复，按压与交互态，读屏语义，以及常驻与一次性两张动效注册表，以本文为准。色板、材质、圆角、间距、字号、布局、日历格状态和 frontmatter token（含 `modal-overlay`）仍在 `DESIGN.md`。不要并列第二套「目标稿」或「实现基线」；已审查数值不要按旧稿回改。

## 规则

已在屏幕上成立、改 UI 时沿用：

- 交互语义（issue #57）：每个可点控件（bindtap/catchtap，sheet 的 `catchtap="noop"` 泄泡盾除外）都带 `aria-role` 与可读 `aria-label`；弹层遮罩本身是「关闭」操作，按用途命名（关闭月份选择/当日操作/日历图例/预测说明/本月小结/使用说明）。选中态用 `aria-checked` 表达并与 `active` 类同条件绑定（单选组如经期状态、密度、月份格、绑定 tab 用 `radio`，可多选或可再点取消的经量/症状 chip 用 `checkbox`）；禁用与加载态用 `aria-disabled` 表达并与 `disabled`/`loading` 类同条件。可看的月份是 2001 年 1 月到 2035 年 12 月，与选月的年份范围是同一对常量（issue #159）：到了一端，那一侧的月份箭头禁用，透明度 0.35，按下不缩放、不着色，`aria-disabled` 与 `disabled` 同条件；点按和滑动都不翻月，也不提示。picker 与输入框带 `aria-label`。同步状态胶囊（`.sync-pill`）为 `status` 角色、朗读名与 `syncStatusText` 同源，同步状态变化即可朗读（issue #106）。日历格保持 `aria-label="{{item.ariaLabel}}"` 领域朗读（日期+经期/欢乐时光/预测/节日/调休）与 `aria-hidden="{{item.isEmpty}}"` 空白格隐藏，角色为 button；语义文案唯一来源仍是 `utils/homeCalendarState.js`。弹层读屏模态（issue #155、#235）：首页三个底部弹层、设置「使用说明」与共享确认面板用同一套表达。面板本体不写 `aria-role`，只有读屏名，是弹层用途（月份选择、当日操作、日历图例/预测说明/本月小结、使用说明；信息弹层随当前内容取 `infoSheetName`），遮罩读「关闭」加同一名称。模态上下文由遮罩名、面板名和被隐藏的背景三者给出，不靠角色。宿主里只有遮罩和面板，读屏顺序固定为遮罩 → 面板名 → 标题行（标题、副标题、「关闭」）→ 面板内控件。任一弹层处于 open 或 leaving 时，页面根下的背景块（顶栏、未绑定/加载失败、骨架、内容）`aria-hidden` 与 `page-obscured` 同一状态，最后一个弹层卸载的同一次更新里恢复；弹层宿主直接挂在页面根下，不在被隐藏的块里。平台边界以微信 aria-component 文档为准（https://developers.weixin.qq.com/miniprogram/dev/component/aria-component.html）：基础库 2.7.1 起只支持部分 ARIA 标签；可设的 `aria-role` 参照 MDN「Widget Roles」，部分 role 在移动端可能无效，dialog 不在其中，所以面板不写这个角色；文档列出 `aria-modal` 却没说行为，不写，背景隔离只靠 `aria-hidden`。微信没有把读屏焦点移到某个 view 的接口（`wx.checkIsOpenAccessibility` 只回答读屏是否开启），关闭后焦点落点由系统决定，不保证回到触发器；能保证的是背景按原文档顺序恢复，触发器名称和位置不变；图例由顶栏「图例」或一次性配对欢迎条直接打开，预测说明与本月小结分别由状态行和小结行直接打开。属性写对不等于读屏可用，VoiceOver/TalkBack 实听结果以验证记录为准。护栏：`tests/interaction-semantics.test.js`、`tests/index-page.test.js`、`tests/settings-flow.test.js`。
- 单选组、经量与装饰字形（issue #242）：记录分类、日历信息密度、绑定方式、选月面板月份、经期状态这五个容器使用 `aria-role="radiogroup"`，读屏名分别为「记录分类」「日历信息密度」「绑定方式」「月份」「经期状态」，子项仍是 `radio` + `aria-checked`。微信 [aria-component](https://developers.weixin.qq.com/miniprogram/dev/component/aria-component.html) 文档把可设角色指向 MDN [Using ARIA](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/ARIA_Techniques) 的 Widget Roles：`radiogroup` 列在该页 Composite roles，属于复合控件；`heading` 只列在 Document structure roles，不在微信指向的控件角色范围，所以页面标题与弹层标题不写 `heading`。经量虽然一次只选一项，但再点已选项会取消，保持 `checkbox`，不改成 `radio` / `radiogroup`；选项读屏名为「经量 {{item.label}}，单选，再点取消」。首页未绑定画面与绑定页的 #271 双琉璃心徽章、欢乐时光列表行内的装饰 ♥ 都写 `aria-hidden="true"`；日历格和快捷入口的既有整体读屏名不变。
- 欢乐时光月份展开/收起（issue #109、#266、#274）：卡头整体是 button，`aria-expanded` 与展开状态同条件，读屏名「YYYY年M月，N 条欢乐时光，已展开/已收起」；右端使用读屏隐藏的 24rpx 几何下折角，`0deg → 180deg` 随状态以 `--duration-state`、`--ease-out` 旋转，不再显示裸「展开 / 收起」文字。尚无手动选择时只展开最近一个有记录的月份，其余收起；收起且该月有备注时，读屏名在状态前带第一条非空备注摘要，卡头标题下也显示这条单行截断摘要，展开时不重复渲染。记录行始终挂载在外层 `.fold-grid` / 内层 `.fold-inner` 中，外层以 `grid-template-rows: 0fr → 1fr` 和透明度做 `--duration-state` 过渡；收起时 `aria-hidden=true`、`pointer-events:none`，展开后恢复，避免读屏或点按落入不可见行。卡头按压底色与缩放遵循 90ms / 180ms 双拍。减弱动效下网格、透明度和折角都即时切换。手动选择只在页面内存，保存后展开目标月份，新到月份保持收起。
- 经期年份与月份展开/收起（issue #187、#266、#274）：年份和月份卡头都为整行 button，保留 `aria-expanded`、至少 88rpx 触控高度与完整读屏名，右端使用同一枚读屏隐藏的几何下折角，不再使用文字「展开／收起」。年份和月份默认全部展开，分别保留页面内手动选择；收起年份不清空月份选择。点击通过双层 `.fold-grid` / `.fold-inner` 的 `0fr → 1fr`、透明度和折角旋转完成 `--duration-state` 连续过渡，记录行保持挂载但收起时 `aria-hidden=true` 且禁止指针命中；减弱动效下即时切换。手动选择只保留在页面内存，刷新与切换分段保留，页面重新创建恢复默认。按记录身份进入编辑；确认保存后展开开始日期所属年／月，开始年月改变时移组，删除后移除空月与空年。取消或保存失败不改变分组选择。
- 动效与性能边界（issue #58）：缓动只有 `--ease-out`（`cubic-bezier(0.16,1,0.3,1)`）与标准关键字（ease/ease-in-out/linear 等）；bounce/elastic 式 overshoot 曲线（cubic-bezier 的 y 参数超出 0–1）与 `--ease-spring` / `--transition-spring` token 已退役，bind 页 `bounceIn` 回弹入场同步改为无回弹的 `heroIn`，禁止同类曲线以任何命名回归。一次性时长只有七档 app 级 token（issue #111；第六档由 issue #165 加入，#270 增加按下拍）：`--duration-press-in` 90ms（`:active` 与对应 hover 规则的按下贴合）、`--duration-press` 180ms（可点控件基础态的松手回弹：缩放、底色、描边与柔光层透明度，见「按压的四路」；阴影本身不进过渡）、`--duration-state` 200ms（选中、颜色、描边、焦点边框，后台刷新时日历变暗，以及当日详情的淡入 `dayDetailFade`）、`--duration-enter` 240ms（整页淡入 `pageEnter`、弹层遮罩淡入、弹层内容块进场、同步胶囊入场、翻月滑入、绑定页显现 `bindReveal`）、`--duration-exit` 200ms（弹层面板、内容块与同步胶囊离场，遮罩淡出）、`--duration-sheet` 280ms（弹层面板升起）、`--duration-emphasis` 600ms（今天与「预」的一次性光晕，亮起再落回；记录成功的 ♥ 与色带、建好房间时绑定页 ♥ 的漾开，issue #167）。延迟只有一档 `--delay-stagger` 40ms，只给弹层内容块进场错相用（issue #166，见下文「弹层标题与内容错相」），别的 transition 不写延迟；时长、曲线和延迟都只写在 `transition` 简写里，不写长写。一次性关键帧动画的延迟也只有一档 `--delay-return` 300ms，只给记录成功反馈等返回转场走完（issue #167，见下文「记录成功反馈」），别的一次性动画不写延迟，延迟同样只写在 `animation` 简写里。按压只属于可点控件，容器和不可点的行不缩放、不变底色（issue #113，取代 issue #81 的逐页豁免）。微信里每个可点控件（`bindtap`/`catchtap`，`catchtap="noop"` 除外）都带 `hover-class`，并且和对应的 `:active` 写在同一条规则里，开发者工具才会画出按压（issue #122，issue #145；护栏 `tests/design-token-guardrail.test.js`）。所有挂载 `hover-class` 的节点自 #270 起显式声明 `hover-start-time="20"` 与 `hover-stay-time="70"`，设计护栏展开共享模板后逐个检查，漏标即失败。类名重复控件自己的类，例如月份箭头 `nav-btn-hover`，危险行 `danger-hover`，危险按钮 `btn-danger-hover`，返回键 `nav-back-hover`。按压着色落在可以过渡的 `background-color` 上（海军实底之上的平涂层），时长仍是 `--duration-press`，不写进 `background-image`。方向仍是 issue #122 的海军实底上平涂着色。`:active` 规则保留。位移、缩放、入场、离场用 `var(--ease-out)`；只变颜色或底色用 `ease`；导航头光斑 `float` 的来回漂移用 `ease-in-out`（周期仍是 8s 与 6s）。除 `--ease-out` 定义外不写 cubic-bezier。组合变量 `--transition` 已退役。常驻动画周期、减弱动效替代和 `heroIn` 0.6s 仍用字面时长。持续动画（`infinite`）只在下文「常驻动画注册表」登记，逐项写挂在哪、用途、节奏、弹层遮挡与页面不可见时的行为和减弱动效替代；新增或删除持续动画时同步那张表与测试注册表。播一次的关键帧动画登记在「一次性动效注册表」，逐项写挂在哪、用途与触发、时长与曲线、中断与取消、弹层遮挡与页面不可见时的行为和减弱动效替代，同样与测试注册表同步（issue #165）。周期只写在 `animation` 简写里，不写 `animation-duration` 长写；错开起点用负延迟。玻璃 blur：哪些面模糊见 `DESIGN.md`「玻璃叠层」的登记；单面 ≤20px，全屏遮罩 ≤8px（共享底部弹层遮罩是 `DESIGN.md` frontmatter `modal-overlay` 登记的 8px，88% 海军底上更大的 blur 看不出差别）。按文件的玻璃面数量棘轮已退役（issue #163）。阴影：颜色与透明度由 `DESIGN.md` 的阴影注册表管；按文件的 `box-shadow` 声明数棘轮同样退役（issue #163）。`@media (prefers-reduced-motion: reduce)` 政策：去掉位移、缩放、旋转的过渡与动画以及装饰动画（位置和大小直接落到终态），状态反馈走无位移通道——加载=透明度脉冲（不静默）、同步中=玫瑰点静态色、骨架=静态哑光占位块、按压=即时 scale + 既有底色变化、弹层=进出立即到位、88% 海军遮罩保留层级（issue #116）、日历切换=即时替换（翻月滑入为 none，月份标题文案变化承载状态）、今天与「预」的光晕照常（只动透明度，是温和的反馈）、记录成功的 ♥ 只淡入不缩放、色带照常淡入（issue #167）、建好房间时绑定页 ♥ 不漾开、已绑定卡直接出现（issue #167）。滑动翻月（issue #137、#272）：日历区域用 WXS 判定，与弹层拖动同一种模式；水平主导后由视图层阻尼跟手，水平位移超过 48px 且大于竖直位移才翻月，否则回弹并留给轻点和竖向滚动；过阈值后一次页面更新完成，和箭头翻月同一段 28rpx 滑入（见下条「翻月滑入与日历状态强调」）；减弱动效下不跟手、即时替换。日期格按压的 6% 白圆角微亮底与缩放共用按压双拍，减弱动效下即时切换。两个编辑页的边框/背景过渡由页面级 reduced-motion 块即时切换，无渐进（issue - 翻月滑入与日历状态强调（issue #165）：这一条取代 issue #137 的翻月无动画规则。箭头、滑动、选月和回到今天都在同一次页面更新里换上月份标题和那个月的格子，不在渲染回调里补排格子（原来选月和回到今天先画出新标题，下一帧才换格子）。翻月时格子从翻月方向滑入：下一月从右、上一月从左，位移 28rpx（合并日历卡与网格 `overflow-x: hidden`，横向跟手和滑入都不出卡片），透明度 0.5 → 1，时长 `--duration-enter`，曲线 `--ease-out`。动的是格子外一层没有盒子的 `.calendar-days`（无内外边距、无描边、不定宽高），卡片、周头和月份标题不动，日期格仍只有自己的按压缩放；整日点按范围和几何账本不变，到了可看月份的两端照旧什么都不发。方向记号 `calendarFlip`（`next-a`、`next-b`、`prev-a`、`prev-b`）跟着那次日历提交走，不用计时器，数据和操作都不等动画：滑入进行中（240ms 内）同方向再翻，只换数据，进行中的滑入接着播，不续期；反向就换成另一方向从头播；播完后再翻，a、b 交替从头播（类名变了 CSS 才会重播）；选月、回到今天和未绑定或加载失败画面取消滑入，新月份即时替换。#272 起 WXS 在水平主导后只对 `.calendar-days` 视图层跟手，常规阻尼 0.28，2001-01 向左禁翻与 2035-12 向右禁翻为 0.12；未达原 48px 阈值或取消以 `--duration-state` 200ms 回弹归零，过阈值先清零内联位移再走原翻月动作。轻点与竖直滚动不启动跟手。系统 touchcancel 只清除本次追踪并回弹，不翻月，也不触发滑入；下一次触摸可重新开始。减弱动效下不跟手，月份即时替换。状态强调只有两处，各有明确的触发：回到今天（首页按钮或选月面板）时，今天的日期胶囊位置亮起一圈更亮、更粗的薰衣草描边（4rpx，`rgba(196,160,210,0.95)`）再落回；关掉开着的预测说明时，当月的「预」在描边处亮一圈金再落回（当月没有「预」就不亮，图例、本月小结和离场途中的重复关闭不触发）。光晕是伪元素上的描边（「预」另有一层淡金底），不是阴影，只动透明度：0 → 1 → 0，`--duration-emphasis` 600ms，播一次，不循环。记号 `calendarEmphasis`（`today-a`、`today-b`、`predict-a`、`predict-b`）只跟着触发它的那次提交，之后任何一次日历更新（翻月、选月、记录变化、刷新）或未绑定和加载失败画面都去掉它，换月和节点重建不会重播。光晕只在记号作用域下存在，静止的日历一点不变；经期中的今天同样显示日期胶囊，光晕仍围住日期；重叠日（经期里不画「预」）和各个标记的含义不变。光晕峰值时被围住的标记照样读得清：今天的光晕不铺底（日期就在框里，原来再叠 30% 玫瑰底，峰值时玫瑰日期只剩约 3:1），描边向内画在框边、不压数字，日期在胶囊、调休格和色带上的峰值都 ≥4.5:1；「预」的淡金底叠满时仍 ≥4.5:1（`tests/contrast-guardrail.test.js`，描边内沿离字形由 `tests/calendar-micro-labels.test.js` 钉住）。减弱动效下翻月即时替换，光晕照常。两种动画逐项登记在「一次性动效注册表」。护栏：`tests/index-page.test.js`、`tests/motion-performance.test.js`。
