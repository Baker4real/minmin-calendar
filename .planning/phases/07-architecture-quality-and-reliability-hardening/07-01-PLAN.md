## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mini Program page to `utils/cloud.js` | Untrusted page event data becomes cloud operation input. |
| `utils/cloud.js` to `wx.cloud.callFunction` | Transport can fail independently from application-level `result`. |
| Local storage to RoomSession | Cached `roomCode` is untrusted cache, not membership truth. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | `utils/room.js#repairCachedRoom` | mitigate | Verify cached room against `getMyRoom` before treating it as valid per D-03. |
| T-07-02 | Denial of Service | `utils/cloud.js#createRoomDataClient` | mitigate | Classify timeout/network errors as retryable outcomes with explicit retry descriptors per D-02. |
| T-07-03 | Elevation of Privilege | `utils/cloud.js` | mitigate | Do not move room authorization to client; keep `dataOp` as server authority. |
