<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Settings page to clipboard/share/file APIs | Sensitive shared records may leave the app during export. |
| Settings page to RoomSession | Local cache operations can affect user binding state. |
| Settings export to RoomDataClient | Export reads room-authorized records before writing local JSON. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-07 | Information Disclosure | `utils/settingsFlow.js#exportRecordsAsJson` | mitigate | Preserve explicit user-triggered JSON export and distinguish share success from clipboard fallback. |
| T-07-08 | Tampering | `pages/settings/settings.js#clearData` | mitigate | Keep settings clear local-only; never call `leaveRoom` or cloud delete from this flow per D-06. |
| T-07-09 | Denial of Service | export data loading | mitigate | Hide loading and return explicit retryable/failure outcomes for cloud or file-write errors. |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan; use existing WeChat APIs and Node tests. |
</threat_model>
